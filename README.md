# まるっと — Xアイコン工房

日本語のアイコン・ヘッダー作成アプリ。ブラウザ内でSVGパーツを組み合わせて4候補を作り、配色・背景・文字を調整してPNGを保存できます。APIキー・依存パッケージは不要。入力の送信や保存はせず、再読み込みで編集内容は消えます。

## 起動

Node.js 20以上で、このディレクトリから `npm run dev` を実行し、ブラウザで `http://localhost:3000` を開いてください。ポートは `PORT` で変更可能。`npm test` でテストします。

## 使い方

1. アカウント名・プロフィール・方向性・絵柄・モチーフを選ぶ。
2. 「4つの候補をつくる」を押し、候補を選ぶ。
3. 配色・背景・ヘッダーの文字を調整する。
4. アイコン（400×400）とヘッダー（1500×500）のPNGを保存する。

20種類のテイストは線・配色・質感による簡易表現です。自由なアニメ作画などはしません。プロフィールからのモチーフ選択はキーワードに基づきます。大人向けの自動選択は月の記号です。全パーツは非アダルトで、実在するブランドのロゴは使いません。

## 将来のAPI接続

`src/provider.js` の `partsProvider.generate(input)` が候補生成の差し替え箇所です。現在は編集可能な設定を4件返します。AI接続時にはサーバーに生成エンドポイントを用意し、プロバイダーを置き換えます。APIキーはサーバー側で管理し、入力・出力検証、非アダルト画像の制約、料金・回数制限を実装してください。画像を直接返すAPIの場合はプレビュー・書き出しのアダプターも必要です。現時点でAPI呼び出しや従量課金はありません。

静的ファイルとしてホスティング可能です。

## GitHub Pagesでの公開

公開用の静的ファイルは `gh-pages` ブランチへ配置します。GitHubリポジトリの **Settings → Pages → Build and deployment** で、Sourceを **Deploy from a branch**、Branchを **gh-pages**、フォルダを **/(root)** にして **Save** してください。

公開先は `https://xxx0326-byte.github.io/codex-x-icon-create/` です。初回は反映まで数分かかる場合があります。JavaScriptとCSSの参照は相対パスなので、リポジトリ名を含むPagesのURLでも動きます。Codex内のHTMLプレビューではなく、公開されたURLをブラウザで開いてください。

更新時は `main` の `index.html`、`style.css`、`src/` を `gh-pages` のルートへ反映してください。サーバー・テスト・開発ファイルの公開は不要です。

## ChatGPTで作った画像を取り込む

初期画面の「ChatGPTの画像を取り込む」で、名前・プロフィール・20種類の絵柄からプロンプトを作成できます。コピーしてChatGPTに貼り付け、画像を作成・保存した後、PNG・JPEG・WebPを取り込んでください。アプリがChatGPTを自動操作することや、画像生成APIを呼ぶことはありません。まるっと側の従量料金はなく、ChatGPTの生成可否・上限は利用プランに従います。

アイコンとヘッダーはそれぞれ最大4候補を取り込み、候補ごとに拡大・左右・上下の位置を調整できます。アイコンは円形プレビュー、保存は正方形400×400、ヘッダーは1500×500です。透明部分はPNGで維持されます。ヘッダーを生成する際は作成したアイコンをChatGPTに添付すると、統一したデザインを依頼できます。

取り込んだ画像はブラウザのメモリ内だけで処理します。新しい取り込みはその種類の候補を置き換え、再読み込みで画像・編集内容が消えます。1枚20MB・4000万画素まで。非アダルトな画像を使用してください。従来の作り方は「パーツで作る」に残っています。
